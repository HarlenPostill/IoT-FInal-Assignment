Try a full cycle

  1. Select 65 dB and press Start stream. Serial should show fresh noise.
  2. Select 100 dB and wait about 5 seconds. At the default 90 dB / 3 s trigger, the servo presses once and returns.
  3. Leave it high: the press count should stay the same.
  4. Select 65 dB for at least 4 seconds after the servo returns. Armed should become Yes. Select 100 dB to trigger again.
  5. Press Stop. Noise becomes stale after roughly 2.5 seconds.
Your board’s saved trigger settings take precedence. The door sensor runs independently.
